# Physics 101 — Interactive Virtual Laboratories

**Undergraduate physics | Interactive simulations | Inquiry-based learning**

[**Launch the interactive laboratories**](https://noonhub-ai.github.io/physics-101/)

## Overview

Physics 101 is a growing collection of browser-based interactive laboratories designed to help undergraduate students connect mathematical descriptions of motion and vectors with physical intuition. Instead of only reading worked examples, students can manipulate quantities, observe visual changes, explore relationships, and check their understanding.

The resources are developed to supplement university-level physics instruction and are accessible through a modern web browser, including on mobile devices.

## Laboratories

### Chapter 1 — Vectors

- [Vector Playground](vector_playground.html) — explore vector magnitudes and directions
- [Vector Components Explorer](vector_components_explorer.html) — investigate Cartesian components
- [Vector Addition](vector_addition.html) — build and interpret resultant vectors
- [Vector Subtraction](vector_subtraction.html) — visualize vector differences
- [Dot Product](dot_product.html) — examine the scalar product and the role of angle
- [Cross Product](cross_product.html) — explore the vector product
- [Polar and Cartesian Coordinates](polar_cartesian.html) — convert between coordinate descriptions
- [Practice Quiz](practice_quiz.html) — consolidate and check understanding

### Chapter 2 — Motion in One Dimension

[Open the Chapter 2 laboratory collection](chapter2/index.html)

The chapter includes ten laboratories on position, displacement, velocity, position–time graphs, acceleration, velocity–time graphs, kinematics, vertical motion, launch from a building, and free fall.

## Learning objectives

Students are encouraged to:

- Connect physical quantities with geometric and graphical representations.
- Predict outcomes before changing simulation parameters.
- Explore the relationships among position, velocity, acceleration, and time.
- Compare visual observations with mathematical calculations.
- Develop independent problem-solving and conceptual reasoning skills.

## How to use

1. Open the [live website](https://noonhub-ai.github.io/physics-101/).
2. Choose a chapter and an interactive laboratory.
3. Follow the activity instructions, change the available parameters, and examine the results.
4. Use the exercises and practice quiz to consolidate learning.

No installation or GitHub account is required to use the published laboratories.

## Implementation

The activities are implemented as web pages using HTML, CSS, JavaScript, and interactive browser graphics. GitHub Pages hosts the student-facing website.

The project uses AI-assisted development. The physics content, learning goals, instructional approach, scientific review, and iterative testing are directed by **Dr. Najwa Al Bouzieh**. AI assistance is used in implementing and refining the web interfaces.
