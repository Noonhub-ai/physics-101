Key ideas from Chapter 1 (pages 2–5)

Scalar vs. vector
A scalar has magnitude only; a vector has both magnitude and direction.
Equal vectors
Two vectors are equal if they have equal magnitudes and point in the same direction—even if located in different places.
Negative vector
−A has the same magnitude as A but points in the opposite direction.
Scalar multiplication
For B = cA, |B| = |c||A|. Positive c keeps the direction; negative c reverses it; c = 0 produces the zero vector.

Mathematical note: for negative c, magnitude uses the absolute value |c|. The zero vector has no unique direction. This lab focuses on the concepts illustrated on pages 2–5 of the provided chapter.
