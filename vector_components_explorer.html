Step-by-step worked solution

Chapter approach: Cartesian ↔ polar components

Angles use the standard convention: measured counterclockwise from the positive x-axis. For any nonzero vector, use atan2(Aᵧ, Aₓ) to identify the correct quadrant. A zero vector has no defined direction.
